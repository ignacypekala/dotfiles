### Prohibitions
Unless explicitly prompted to, do not:

- edit files in response to a question,

- use state-altering git commands (stay away from: git commit, git reset etc. However git status, git grep, etc. are fine).

### Guidelines
- Avoid excessive or unnecessary tool/fs usage. For example: when asked a simple follow up question, give an answer straight away instead of re-running the entire test suite despite zero code changes.

- Whenever you try to run a non-trivial command, especially a script of your creation, create a brief description of what it does and what it tries to accomplish. Print it before trying to run the command.

- Do not print out large outputs directly, instead create a markdown file and
open it in the browser.
